# DeepSeek RAG Demo

This is a local document question-answering demo. Documents and the vector index are stored locally, while answers are generated by the DeepSeek API.

## 1. Install dependencies

Python 3.10 or newer is recommended:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
```

## 2. Configure the API key

Copy `.env.example` to `.env` and add your DeepSeek API key:

```env
DEEPSEEK_API_KEY=your_api_key
DEEPSEEK_MODEL=deepseek-chat
```

## 3. Build the document index

The embedding model is downloaded on the first run:

```bash
python ingest.py
```

## 4. Start the web app

```bash
streamlit run app.py
```

Open the URL shown by Streamlit. Add `.txt`, `.md`, or `.pdf` files to `data/documents/`, then click **Sync document index** in the sidebar. The sync operation skips unchanged files, updates changed files, adds new files, and removes deleted files.

For a full rebuild, run:

```bash
python ingest.py --reset
```

## Example questions

- What are the onboarding steps for a new employee?
- What is the daily meal allowance during business travel?
- Which materials are required for an expense claim?
- Does the company support remote work?
- What is 1+1?

The remote-work question is not covered by the sample documents. The assistant should say that no relevant information was found in the documents.
