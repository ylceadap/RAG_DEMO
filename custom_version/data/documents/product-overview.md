# Xinghe Knowledge Base Product Overview

Xinghe Knowledge Base is an internal knowledge assistant for small and medium-sized businesses. Employees can upload policies, product documents, and project materials and search them using natural language.

## Main Features

The product supports PDF, Markdown, and TXT files. It extracts document content, builds a retrieval index, and shows references with each answer. Administrators can rebuild the index when new content is added.

## Support

Basic-plan users receive email support with a response within 24 hours on business days. Professional-plan users can use online support from Monday through Friday, 9:00 to 18:00.

## Data Handling

Document indexes are stored in a local database in the deployment environment. Administrators should avoid uploading unnecessary sensitive information such as ID numbers, bank-card numbers, or passwords.
